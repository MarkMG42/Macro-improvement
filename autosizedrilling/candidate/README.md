# Тестовая сборка 1.1.2

Собрана из `../src/` для .NET Framework 4.8/x64. Сборка и 23 проверки геометрии прошли; запуск в SolidWorks ещё не выполнялся.

Для ошибки «центр выбран правильно, но ручной горизонтальный размер от той же кромки отличается» используются явный горизонтальный API и сверка значения после перестроения. Диагностические журналы сохраняются локально в `%LOCALAPPDATA%\AutoSizeDrilling\Logs`. Описанный случай на реальной модели пока не воспроизведён.

Не заменяйте рабочую DLL до проверки на копии чертежа. Исходная версия находится в родительской папке. Этот PDB относится только к новой DLL.

Перед созданием размеров макрос переключает выбранный вид на проекционные размеры и оставляет этот режим после успешного запуска. Это может пересчитать существующие размеры этого вида. При ошибке предпринимается восстановление исходного режима. Проверка этого переключения в SolidWorks ещё не выполнялась.

Изменения, сборка и сценарии натурной проверки: [CHANGES.md](../CHANGES.md).

Контроль целостности в этой папке: `sha256sum -c SHA256SUMS`.
