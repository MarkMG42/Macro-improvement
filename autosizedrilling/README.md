# AutoSizeDrilling

Макрос автоматической простановки размеров швеллера, трубы и уголка на чертеже SolidWorks.

Исправленная версия с исходным C#-кодом находится в `src/`, регрессионные проверки — в `tests/`, тестовая сборка — в `candidate/`. Изменения, ограничения и порядок проверки в SolidWorks: [CHANGES.md](CHANGES.md). Оригинальная DLL ниже сохранена для отката и сравнения.

В репозитории сохранён полный комплект предоставленных пользователем файлов без изменения бинарного содержимого:

- `AutoSizeDrilling.dll` — сборка макроса, VB.NET, .NET Framework 4.8, x64; версия 1.0.0.0.
- `AutoSizeDrilling.pdb` — отладочные символы; это не исходный проект.
- `SolidWorks.Interop.sldworks.dll`, `SolidWorks.Interop.swconst.dll` — предоставленные библиотеки взаимодействия с SolidWorks.
- `SHA256SUMS` — контрольные суммы этих четырёх файлов.

Проверка целостности файлов из этой папки: `sha256sum -c SHA256SUMS`.

По коду сборки требуется запущенный SolidWorks, активный чертёж и один выбранный чертёжный вид. Точка входа — `AutoSizeDrilling.SolidWorksMacro.main`, вызывающая `AutoSizeDrill.Run`. Данный комплект не содержит исходного VSTA-проекта или инструкции по его установке: совместимость и загрузка в конкретной версии SolidWorks ещё не проверены. DLL не следует запускать как самостоятельную программу.

Результаты статического анализа оригинальной DLL — в [REVIEW.md](REVIEW.md). Оригинал не изменялся; исправленная версия собрана отдельно и ещё не испытана в SolidWorks. Для воспроизведения конкретной ошибки полезны исходный `.slddrw`, связанные модели и пример ожидаемого и полученного размера.
